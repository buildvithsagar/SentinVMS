# Project Customization Rules

*   **Phase Documentation Rule:** After every phase, the agent must create and save the context file, Mermaid code file, phase file, tasksheet, and implementation plan file inside the `phase_documentation` folder.
*   **UI Design System Rule:** Always maintain a clean, professional **Subtle Dark Glassmorphism** design system across all screens in SentinVMS (Base Canvas: Dark Slate `#0F172A`, Translucent Glass: `BackdropFilter` with `sigmaX: 8–12, sigmaY: 8–12` & low opacity `0.04`–`0.08`, Primary Accent: Subtle Electric Teal `#2DD4BF` for active states only, Alert Accent: Crimson Red `#EF4444`). Keep UI clean, balanced, and non-dramatic (Apple/Verkada security software aesthetic without heavy gaming glows or flashy over-the-top effects).
